## 💡 The Business Twist ("Useless Calculator")

1. **Free Tier (1 Calculation)**: Users can calculate any complex expression (basic arithmetic, trigonometry, logs, powers, roots, factorials).
2. **Quota Exhausted**: As soon as the user tries a 2nd calculation, the calculator locks up, plays an alert buzzer, shakes the screen, and triggers a high-converting **"CalcPro VIP Pass"** SaaS paywall.
3. **VIP Tiers & Unlock**:
   - **Weekly Starter**: $2.99 / wk
   - **Annual VIP**: $29.99 / yr (*70% OFF*)
   - **Lifetime Math God**: $59.99 (One-time payment)
   - **Secret Bypass Promo Codes**: Enter `FREEMATH`, `DEVBYPASS`, or `TRIAL7` for instant VIP unlock!
   - **Mock Checkout**: Instant Apple Pay / Google Pay / Card flow with a celebratory confetti blast.

## 📱 Features

- **Standard Arithmetic**: Addition, subtraction, multiplication, division, percentage, parentheses, negation.
- **Scientific Suite**:
  - `sin`, `cos`, `tan`, `asin`, `acos`, `atan`
  - `DEG` and `RAD` interactive angle mode toggle
  - `log` (base 10), `ln` (natural log)
  - `x²`, `xʸ`, `√`, `∛`, `x!` (factorials)
  - Constants ($\pi$, $e$)
  - Memory: `MC`, `MR`, `M+`
- **Calculation Tape / History Drawer**: Slide-out panel preserving past calculations with one-click restore and return buttons.
- **Web Audio API Sound Engine**: Tactile haptic key clicks, paywall buzzers, and celebratory fanfare audio synthesis (zero latency, zero external asset dependencies).
- **Responsive Mobile Frame**: Luxury glassmorphism design system inspired by iOS dark mode.
- **Developer Sandbox Bar**: Test and reset quotas, toggle VIP, and preview paywalls with one click.

## 🚀 Getting Started

### Local Setup
No build steps or dependencies needed! Just open `index.html` in your browser:

```bash
# Clone repository
git clone https://github.com/Myparadox-creator/Useless_calculator.git

# Navigate into project directory
cd Useless_calculator

# Run with any local server (e.g. Node, Python, or Live Server)
node server.js
```

Then visit [http://localhost:8888](http://localhost:8888) in your browser.
